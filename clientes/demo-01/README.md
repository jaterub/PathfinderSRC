# Primer cliente · ejemplo público

`cv.md` conserva la experiencia, formación, idiomas y competencias del CV aportado. Se han retirado nombre, dirección, correo, teléfono y fecha de nacimiento para la copia pública. El documento de origen declara ficticias las empresas y experiencias profesionales; no se presupone que todos sus demás datos sean ficticios ni que esta copia garantice anonimato completo.

El original no se publica ni se modifica. No se incorpora el CV del usuario de Profesión.

Área profesional: asesoría fiscal y tributación. Todavía no se han fijado objetivo, salario, ubicación deseada, modalidad ni exclusiones. El CV por sí solo no acredita estas preferencias.

En PR 2 se añadirá el perfil validado y ofertas de ejemplo. En PR 3 se generará el dashboard. No existen todavía esos archivos ni resultados de evaluación.
